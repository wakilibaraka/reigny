# REIGNY. — Avant-Garde Digital Creative Agency

An ultra-modern, high-performance multi-page digital agency website engineered with Tailwind CSS, typography hierarchies (Playfair Display, Inter, Space Mono), glassmorphism, dynamic Light/Dark mode, ambient mesh gradients, fluid blob animations, and interactive components.

---

## 🌐 Pages & Structure

- **`index.html`** — Homepage (Hero with morphing blob, Marquee ticker, Selected Works bento grid, Process timeline, Leadership showcase, Lead capture CTA, Live chat widget).
- **`work.html`** — Curated portfolio archive and project gallery with category filtering and interactive bento cards.
- **`services.html`** — Comprehensive breakdown of the 6 core agency pillars:
  1. Graphic Design
  2. Digital Marketing
  3. SEO Services
  4. Social Media Marketing
  5. PPC & Google Ads
  6. Custom Web Development
- **`agency.html`** — Agency story, mission, core values, and executive leadership profiles (Reinhard Were & Dr. Malach Khaduli).

---

## ⚡ Features

- **Zero-Build Architecture**: Runs natively in any browser or static web server (Hostinger, Cloudflare Pages, Vercel, Netlify, GitHub Pages).
- **Dynamic Theme Engine**: Smooth, persistent Light/Dark mode switcher with anti-FOUC (Flash of Unstyled Content) detection.
- **Micro-Interactions**: Ambient mesh gradients, floating glow orbs, scroll-reveal Intersection Observer animations, and live chat widget.
- **Responsive & Mobile-First**: Built with modern fluid typography and responsive CSS grid.

---

## 🚀 Deployment to Hostinger

1. Download or clone this repository.
2. In Hostinger **hPanel**, navigate to **File Manager** -> `public_html`.
3. Upload `index.html`, `work.html`, `services.html`, and `agency.html`.
4. Your website is immediately live!
