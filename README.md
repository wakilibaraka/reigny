# REIGNY. — Avant-Garde Digital Creative Agency

An ultra-modern, high-performance multi-page digital agency website engineered with Tailwind CSS, typography hierarchies (Playfair Display, Inter, Space Mono), glassmorphism, dynamic Light/Dark mode, ambient mesh gradients, fluid blob animations, and interactive components.

---

## 🌐 Full Website Pages

- **[`index.html`](index.html)** — Homepage (Hero with morphing blob, Marquee ticker, Selected Works bento grid, Process timeline, Leadership showcase, Lead capture CTA, Live chat assistant).
- **[`work.html`](work.html)** — Curated portfolio archive and project gallery with category filtering and interactive bento cards.
- **[`case-study.html`](case-study.html)** — Deep-dive case study: *Neon Noir // Cinematic Brand Metamorphosis* (Problem, Strategy, Visual Stills, +240% Metrics & Testimonial).
- **[`services.html`](services.html)** — Comprehensive breakdown of the 6 core agency pillars:
  1. Graphic Design
  2. Digital Marketing
  3. SEO Services
  4. Social Media Marketing
  5. PPC & Google Ads
  6. Custom Web Development
- **[`agency.html`](agency.html)** — Agency story, mission, core values, and executive leadership profiles (Reinhard Were & Dr. Malach Khaduli).
- **[`journal.html`](journal.html)** — Field notes and thought leadership essays on design critique, culture, and algorithmic growth.
- **[`careers.html`](careers.html)** — Studio culture, manifesto, perks, and 4 active openings (Senior Art Director, Creative Technologist, 3D Artist, Strategist).
- **[`contact.html`](contact.html)** — Project initiation suite with capability selector, budget range estimator, timeline, and direct studio coordinates.
- **[`privacy.html`](privacy.html)** — Client confidentiality, data governance, and intellectual property terms.

## 💻 Local Preview

To view the website locally, launch a local web server:

```bash
# Using Python 3 (built-in on macOS & Linux)
python3 -m http.server 8000
```
Then visit **`http://localhost:8000`** in your browser.

Or simply double-click any `.html` file (e.g., `index.html`) to open directly in your web browser.
